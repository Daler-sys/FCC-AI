Python Mini Camp

Мини‑курс по основам Python в одном HTML‑файле. Пиши код в редакторе и нажимай «Проверить».

1. Переменные и вывод

В Python переменные создаются присваиванием. print() выводит текст.

name = "Алексей"
print("Привет, " + name)

Задание: Создай переменную city со значением «Москва» и выведи фразу: «Я живу в Москве».



2. Условные операторы

Конструкция if-else позволяет выполнять код по условию.

age = 18
if age >= 18:
    print("Доступ разрешён")
else:
    print("Доступ запрещён")

Задание: Переменная score равна 75. Если score >= 60, выведи «Зачёт», иначе — «Пересдача».



3. Циклы и списки

Цикл for перебирает элементы списка. range() создаёт последовательность чисел.

numbers = [1, 2, 3]
for n in numbers:
    print(n)

Задание: Выведи квадраты чисел от 1 до 5 (каждое на новой строке). Используй range(1, 6).



4. Функции

Функция объявляется через def. Она может принимать аргументы и возвращать результат.

def greet(name):
    return f"Привет, {name}!"

Задание: Напиши функцию square(x), которая возвращает квадрат числа. Вызови её для числа 7 и выведи результат.
